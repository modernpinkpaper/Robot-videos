# Robot videos

- `characters/`  the robot animation style (use for any video)
- `formats/podcast/`  the Robot Print Room podcast format (only for podcasts)
- `CLAUDE.md`  rules Claude follows automatically in this repo

Try: open a Claude Code session on this repo and say "make a 60 second video of what life would be like if nobody could lie".

- `menu/`  pick your cast (humans, robots, both, pets) and format (story, skit, talk to camera, reaction, podcast, explainer)
- `camera/`  the moving-camera style used by every video
