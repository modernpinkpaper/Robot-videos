# Pull requests explained (9:16, about 7 minutes)

Teaches only the pull request, using Dalia's real world: making animation videos
(characters, voices, backgrounds, camera moves, new videos). Fifth-grade words.
Mica teaches, "You" is the learner, Chargey is the director who reviews.

Parts: warm up (repo, main, branch) -> 4 ways to see a pull request (a note, a TV preview, a before/after page, a chat)
-> inside a pull request (7 parts) -> 8 steps to make one -> a full story (beach background) -> when to use one (YES)
-> when to wait (NOT YET) -> 4 states (draft, open, merged, closed) -> quiz -> your job as the director -> recap.

Same engine as `videos/github_basics/`. Edit words in `script.py`. Rebuild: `python3 mk.py`, then `./run.sh` (slow, about 35 minutes).
